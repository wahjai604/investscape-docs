## Policy decisions needed before application (answer these with the review)

**P1 — French acronym style.** Recommendation: use French acronyms for universal finance concepts — **TRI** (IRR), **RNE** (NOI), **RPV** (LTV), **RCP** (ROE) — but keep English acronyms for BC-statutory/industry-locked terms — **PTT, DCC, CAC, FSR, CRU, DPI, LTC** — since BC francophone practitioners encounter those in English in every statute and city document. The glossary below is written to this recommendation.

**P2 — Chinese square feet.** Recommendation: **平方呎** in zh-Hant (Hong Kong/Cantonese-Canadian convention, dominant in Vancouver Chinese real estate media) and **平方英尺** in zh-Hans (mainland convention). Written to this below.

**P3 — zh-Hant register.** Traditional-Chinese real estate vocabulary differs between Hong Kong usage (按揭, 首期, 物業) and Taiwan usage (房貸, 頭期款, 不動產). Recommendation: **HK-leaning**, matching Vancouver's Chinese-language real estate press (Ming Pao, Sing Tao). Written to this below — flag if you'd rather lean Taiwan.

**P4 — Consistency rule (not a decision, an instruction):** wherever the prototype already has a wired translation (Proforma rapide / Modèle complet on the hub cards, Taux de capitalisation, Capitaux propres, Flux, Portefeuille, Répartition…), the application pass must **reuse the existing key**, never mint a competing translation. The glossary matches those anchors deliberately.

**Formatting reminders for the application pass:** French uses a space before % and decimal commas in labels (`[2,5 %]` not `[2.5%]`); this extends the fr-CA number formatting already shipped for currency.
