# Community map sharing proposal

Status: proposed bounded feature, not a Community dependency or approved publishing action.

## Recommended first slice
Generate a static map card on explicit request, not continuously. Include selected area, chosen metric/unit/period, visible approved evidence references, attribution, capture time and concise user-editable AI-assisted explanation with citations. Label AI text and uncertainty. No video/live collaborative map initially.
Prepare -> preview included layers/fields/audience -> explicit post. No tool/message posting is authorized by this planning pack. User may cancel.

Public/member evidence permissions and tile/export rights apply to every included layer. Do not assume browser screenshot export works: WebGL preservation, image CORS and attribution require prototype checks. If export rights unclear, omit that layer or offer a permitted text summary.
Default excludes personal Portfolio overlays, exact private addresses, financial figures, hidden Research, tokens and internal IDs. Sensitive optional inclusion requires specific fields and destination review.
Store one bounded image plus compact structured context and allowed references, not an entire dataset. Proposed limit: one image <=1 MB after compression, no automatic recapture. Validate quality, not simply file size. Delivery/storage cost depends on views and retention; no capacity claim.
Optional recreate link rechecks viewer access and current publication. It does not recreate author's private holdings and may differ from original snapshot. Snapshot remains historical; link surfaces revised/withdrawn/unavailable evidence. Downloaded images cannot be revoked.
Moderation, audience/retention/deletion policy, approved AI text handling, and exposure controls remain unresolved. Community remains a separate track and can be built without map sharing.

## Prototype-only tests
Synthetic export, visible attribution, private layer excluded, sensitive labels removed, metadata clean, cancelled share no post, source withdrawal/recreate unavailable, export failure fallbacks. Real Community integration is outside map renderer prototype.
